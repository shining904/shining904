# 하루 1분 맞춤법: 네이버 클립 게시물 시리즈

## 게시물 #1 업로드용 텍스트

**제목**
직장인이 보고서에서 제일 많이 틀리는 맞춤법 5

**본문**
하나라도 틀리면 팀장님은 다 봅니다 👀

1. 돼요 / 되요 → '되어'로 바꿔서 말이 되면 '돼'
2. 결재 / 결제 → 결재는 승인, 결제는 돈 지불
3. 로서 / 로써 → 로서는 자격, 로써는 수단
4. 금새 / 금세 → '금시에'가 줄어든 '금세'
5. 몇일 / 며칠 → 언제나 '며칠'

마지막 장 퀴즈 정답은 댓글로 남겨 주세요!
매일 1분, 헷갈리는 맞춤법을 카드 한 장으로 정리해요.

**태그**

## 월간 15편 계획

| # | 제목 | 다루는 내용 |
|---|---|---|
| 1 | 보고서에서 제일 많이 틀리는 맞춤법 5 ✅ | 되/돼, 결재/결제, 로서/로써, 금세, 며칠 |
| 2 | 카톡에서 티 나는 맞춤법 5 | 웬/왠, 어떡해/어떻해, 할게/할께, 그러고 나서, 오랜만 |
| 3 | 띄어쓰기 하나로 뜻이 바뀌는 말 | 한번/한 번, 큰집/큰 집, 못하다/못 하다 |
| 4 | 메일 첫 줄 맞춤법 | 안녕하십니까, 수고하세요 대신 쓸 말, 드림/올림 |
| 5 | 헷갈리는 '데' vs '대' | 했대(전달) vs 했데(X), -는데 |
| 6 | 맞히다 vs 맞추다 | 정답을 맞히다, 퍼즐을 맞추다 |
| 7 | 가르치다 vs 가르키다 | 가르치다/가리키다, 가르키다는 없는 말 |
| 8 | 이따가 vs 있다가 | 시간 vs 머무름 |
| 9 | 낫다 / 낳다 / 낮다 | 병이 낫다, 아이를 낳다, 키가 낮다 |
| 10 | 회의록 단골 실수 | 역할(O)/역활(X), 일일이, 곰곰이, 깨끗이 |
| 11 | 존댓말 과잉 | "커피 나오셨습니다" 같은 사물 높임 |
| 12 | 외래어 표기 | 메시지, 콘텐츠, 리더십, 워크숍 |
| 13 | 숫자·단위 띄어쓰기 | 10 개, 3시 30분, 제1 회의실 |
| 14 | 이번 달 총정리 + 퀴즈 10문제 | 1~13편 복습 |
| 15 | 구독자 질문 맞춤법 | 댓글로 받은 질문 정리 |

**운영 방식**
- 하루 1편씩 평일에 올리면 3주 만에 15편(월 미션 기준)이 채워져요.
- 반응이 좋은 편은 카드를 넘기는 15초 영상으로 다시 만들어 동영상 클립 조회수도 쌓으세요.
