## 게시물 #1 업로드용 텍스트

**제목**
직장인이 보고서에서 제일 많이 틀리는 맞춤법 5

**본문**
하나라도 틀리면 팀장님은 다 봅니다 👀

1. 돼요 / 되요 → '되어'로 바꿔서 말이 되면 '돼'
2. 결재 / 결제 → 결재는 승인, 결제는 돈 지불
3. 로서 / 로써 → 로서는 자격, 로써는 수단
4. 금새 / 금세 → '금시에'가 줄어든 '금세'
5. 몇일 / 며칠 → 언제나 '며칠'

마지막 장 퀴즈 정답은 댓글로 남겨 주세요!

## 수익 조건 달성 계획
- 조건(블로그·기사 기준, 앱에서 최종 확인): 구독자 1,000명 + 최근 90일 유효 조회수 300만 회
- 300만 ÷ 90일 ≈ 하루 3.3만 회 → 영상 수와 '터지는 한 편'이 핵심
- 매일: 영상 1~2개 + 게시물 1개, 같은 시간대
- 1주마다: 조회수 상위 영상의 표지 문구·주제를 다음 주에 복제
- 금지: 조회수·구독자 구매, 맞구독, 같은 영상 재업로드 (유효 조회수에서 빠지고 심사 탈락 위험)
