# motion-lab — p5 · 캔버스 · 블렌더 · Meshy AI 모션그래픽 작업대

HyperFrames 한 타임라인 위에 **서로 다른 도구로 만든 레이어**를 겹쳐서 모션그래픽을 만드는 작업 틀입니다.
데모: `demo/` ("흙과 불이 빚은 시간 — 이천", 15초 세로) → `demo/out/demo.mp4`

## 도구별 역할

| 레이어 | 도구 | 잘하는 것 | 데모에서 |
|---|---|---|---|
| 배경·질감 | **Canvas 2D** (브라우저 캔버스) | 그라데이션, 빛 번짐, 필름 그레인, 픽셀 효과 | 가마 불빛이 숨 쉬듯 일렁이는 배경 + 그레인 |
| 손그림·입자 | **p5.js** | 붓 터치, 선 드로잉, 파티클, 생성 패턴 | 금색 붓으로 그리는 원(엔소), 떠오르는 불씨 |
| 3D 오브젝트 | **Meshy AI** → **Blender** | 실제 3D 물체를 원하는 카메라 움직임으로 | Meshy가 만든 백자 항아리를 블렌더로 조명·회전 렌더 |
| 글자·구성 | **HTML + GSAP** (HyperFrames) | 키네틱 타이포, 도장, 정확한 정보 | "흙과 불이" 한 글자씩, "이천" 붓글씨 공개, 낙관 |

모든 레이어가 **시간(t)만으로 그려지도록** 만들어서, 몇 번을 렌더해도 같은 결과가 나옵니다
(랜덤은 고정 시드, 파티클은 시간 함수).

## 3D 파이프라인 (Meshy → Blender → 영상)

1. **Meshy로 3D 모델 만들기** (Magnific 경유, 텍스트 또는 사진에서)
   - 텍스트→3D: Meshy 7.1, PBR 재질 포함 약 700크레딧, 3분 내외
   - 사진→3D: 특산물·캐릭터 사진 1장으로도 가능 (Meshy/Tripo/Hunyuan 선택)
2. **블렌더로 렌더** — `blender/render_glb.py` (화면 없이 Cycles CPU)
   ```
   python3 blender/render_glb.py -- --glb model.glb --out frames/ --frames 210 \
       --size 720x720 --preset reveal --samples 20
   blender/encode_alpha.sh frames/ model.webm 30
   ```
   - 프리셋: `turntable`(한 바퀴 회전) · `reveal`(카메라가 다가가며 돌아 보는 영웅 샷) · `float`(둥실 떠서 흔들림)
   - 배경 투명 + 그림자만 받는 바닥 → 어떤 배경 위에도 바로 합성
   - 조명색 바꾸기: `--key 1,0.8,0.6` (따뜻하게) `--rim 0.6,0.8,1` (차갑게)
   - 확인용 한 장만: `--still 150`
   - 속도: 720×720, 20샘플 기준 **프레임당 약 9~10초** (7초 영상 ≈ 30분). 1080은 약 2배
3. **HyperFrames에 넣기**: `<video src="model.webm">` 한 줄 — 알파 채널이 그대로 살아 있음

## 클로드에게 이렇게 요청하세요

```
[motion-lab] 이천 ○○ 홍보 모션그래픽 15초 세로
- 3D 주인공: 이천 쌀 한 톨 / 도자기 / 복숭아 (Meshy로, 사진 첨부하면 그걸로)
- 3D 움직임: reveal (다가가며 돌아보기)
- p5: 붓 터치로 원 그리기 + 불씨 / 꽃잎 / 쌀알 파티클
- 캔버스 배경: 가마 불빛 / 새벽 안개 / 황금 들판 그라데이션
- 글자: "○○○" 한 글자씩, 마지막에 큰 붓글씨 제목 + 도장
- 소리: 국악 퓨전 / 웅장한 오케스트라
```

- 레이어마다 **도구 이름을 붙여** 말해 주면 그대로 나눠 만듭니다.
- 3D 물체는 **사진 1장**이 가장 정확합니다 (텍스트만으로는 모양이 조금 달라질 수 있음 — 데모도 '달항아리'를 요청했는데 뚜껑 있는 항아리가 나왔어요).
- 블렌더 렌더가 시간이 가장 오래 걸리므로, 3D 장면은 **먼저 정지 화면 1장**으로 확인받고 진행합니다.

## 비용 감각 (Magnific 크레딧)

| 항목 | 크레딧 |
|---|---|
| Meshy 텍스트→3D (PBR) | 약 700 |
| 음악 30초 (Lyria) | 150 |
| p5 · 캔버스 · 블렌더 렌더 · HyperFrames | 0 (이 컴퓨터에서 계산) |

## 이 환경에서 확인된 사항

- 블렌더 5.0 (`pip install bpy`) — Cycles CPU 렌더 OK, EEVEE는 화면(GPU) 없이 안 됨
- Meshy 공식 API(api.meshy.ai)는 네트워크 정책상 막혀 있음 → **Magnific 안의 Meshy 엔진** 사용
- Three.js(WebGL 3D)도 npm에서 받을 수 있어, 실시간 3D 레이어가 필요하면 추가 가능
- 사용자 PC의 블렌더를 직접 조종하려면 Magnific Local MCP의 Blender 연결을 쓰면 됨 (PC에 설치 필요)
