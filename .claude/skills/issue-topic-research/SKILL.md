# 이슈 소재 고르기

## 1. 후보 모으기 (10~15개)
- 국내 언론 "많이 본 뉴스"·랭킹(네이트 랭킹 등), 구글 트렌드 대한민국, 주요 일간지 경제·IT·생활 섹션을 최근 3일 기준으로 검색한다.
- 네이버 실시간 검색어는 2021년에 없어졌다. "실검 1위" 같은 표현은 쓰지 않는다.

## 2. 걸러내기 (하나라도 해당하면 제외)
- 사건사고, 범죄 수사, 사망·부상, 연예인 사생활, 정치 공방, 전쟁·안보 분쟁
- 특정 개인을 비난하거나 단정하게 되는 이슈
- 보도가 한 곳뿐이라 교차 확인이 안 되는 이슈

## 3. 점수 매기기 (각 1~5점)
| 항목 | 높은 점수 |
|---|---|
| 검색 수요 | 여러 매체가 다루고, 사람들이 "그래서 뭔데?"를 찾아볼 만한 것 |
| 경쟁 약함 | 같은 주제의 쉬운 요약 콘텐츠가 아직 적은 것 |
| 광고 적합성 | 생활·경제·과학·IT·제도 변화 |
| 설명 가치 | "누가·언제·어떻게"와 배경 설명을 붙일 수 있는 것 |
| 수명 | 시행일 등 며칠 이상 유효한 것은 가산점 |

## 4. 결과 형식
점수 순으로 상위 3개를 고르고, 각 소재마다 다음을 적는다.
- 한 줄 요약
- 확인한 사실 3~5개: 숫자와 날짜, 출처 매체 2곳 이상
- 누가·언제·어떻게 (문장 속에 녹일 재료)
- 주의할 점: 아직 "주장" 단계인지, 수치가 바뀔 수 있는지
- 추천 업로드 시점 (즉시 / 오늘 중 / 시행일 전까지)

## 5. 같은 날 다양성 규칙 (계정 제재 예방)
- 하루 최대 3편까지만 고른다.
- 3편의 분야를 서로 다르게 고르고, 같은 구성으로 찍어낸 듯 보이지 않게 한다.
