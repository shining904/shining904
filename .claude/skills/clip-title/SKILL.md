# 클립 제목 3안

## 구조
`[검색 키워드] + [궁금증/이득 한마디]`

- 검색 키워드는 사람들이 실제로 검색창에 칠 말로 쓴다 (예: "리만 가설", "코스피 급락", "난임치료휴가").
- 키워드는 제목 앞쪽 15자 안에 넣는다.
- 한마디는 다음 중 하나로 쓴다.
  - 질문형: "AI가 풀었다?"
  - 숫자형: "달라지는 것 2"
  - 결론형: "확인된 것만 정리"

## 3안 규칙
1. 질문형 1개, 숫자형 1개, 결론형 1개
2. 제목은 40자 이내, 표지 큰 글씨는 3줄·줄당 8자 이내
3. 과장 금지: "충격", "경악", "100% 확정", 확인되지 않은 단정
4. "주장" 단계인 이슈는 제목에 물음표나 "주장"을 넣는다

## 결과 형식
| 안 | 제목 (본문 입력용) | 표지 3줄 (강조할 단어에 [ ]) |
|---|---|---|

마지막에 추천안 하나와 이유를 한 줄로 적는다.
