# 이슈 콘텐츠 작성 규칙

## 기준 글 (형식을 그대로 따른다)
- 카드: `naver-clip/news/news_20261122.py`의 news01 (리만 가설 편)
- 영상: `naver-clip/motion/news01_riemann.html`
- 새 글을 쓸 때 장 수, 문장 길이, 표지 구성, 부엉이 위치를 이 기준 글에 맞춘다. 규칙을 길게 늘리기보다 기준 글을 보여 주는 쪽이 정확하다.

## 구성 (카드 6~7장 / 영상 7장면, 35~45초)
1. **훅:** 질문형 한 줄과 숫자 하나
2. **무슨 일?:** 누가 언제 어떻게 했는지를 **문장 속에** 넣는다. "누가/언제/어떻게" 표나 라벨은 만들지 않는다.
3~4. **배경 설명:** 처음 보는 사람도 알 수 있게 쉬운 말로 (예: 리만 가설이 뭔지)
5. **핵심 숫자:** 숫자는 카운트업 연출이 가능한 것으로
6. **아직 모르는 것 / 앞으로:** 주장 단계라면 검증 절차를 밝힌다
7. **참여 유도:** A/B/C 질문과 "댓글로 알려 주세요"
- 마지막에 출처 매체 2곳 이상과 "○월 ○일 기준"을 적는다.

## 앞으로는 이렇게 (사용자 피드백 누적)
- 누가·언제·어떻게는 표가 아니라 문장 속에 넣는다.
- 낯선 개념(예: 리만 가설)은 반드시 쉬운 설명 장면을 넣는다.
- 증명·인정 같은 절차는 단계로 보여 준다 (① ② ③).
- 영상은 45초 이내로 한다.
- 캐릭터는 귀여운 부엉이 v2(`naver-clip/ip/owl-reporter-v2`)를 쓴다. 영상에서는 구석에 300px로 작게 넣는다.
- **TTS 대본의 숫자는 전부 한글로 풀어 쓴다** (167년 → 백육십칠 년, 20일 → 이십일, 2년 → 이 년, 0 → 영). 화면 표시는 숫자 그대로 둔다.
- 내레이션은 대본 전체를 **한 번에 이어서** 녹음하고, 문단 사이 쉬는 구간에서 잘라 장면에 맞춘다. 줄마다 따로 생성하지 않는다.
- 내레이션 목소리: ElevenLabs 엔진, 남성 Dylan (Higgsfield `text2speech_v2`, variant `elevenlabs`, voice_id `b847bc29-f184-583a-8ad9-d1f1e16d1a60`)

## 금지
- 뉴스 사진, 방송 화면, 실존 인물 얼굴 (저작권·초상권)
- 확인 안 된 단정, 투자 권유
- 같은 날 같은 구성으로 찍어낸 듯한 글

새 피드백을 받으면 이 파일의 "앞으로는 이렇게"에 한 줄씩 추가한다.
