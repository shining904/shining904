모션그래픽 대화 정리 + 클로드에게 잘 요청하는 법
(카톡방 대화 2026.10.1 ~ 10.10 정리)

1부. 단톡방에서 나온 이야기 정리
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1) 화제의 중심: "p5(p5.js)"
- 방장님(아콘)이 p5.js라는 코드 도구로 손그림 느낌의 모션그래픽 영상을 만들어 화제가 됨
- p5.js = 브라우저에서 "코드로 그림을 그리는" 무료 도구 (브러시, 선, 입자, 패턴 등)
- 힉스필드 같은 유료 생성 서비스가 아니라 클로드가 짠 코드로 그림이 그려지는 방식
- 한계: 실사(진짜 사람·풍경 같은 화면)는 불가능. 그림·그래픽·손그림 스타일 전용
  → 실사가 필요하면 이미지/영상 생성 AI(Magnific, 힉스필드 등)와 섞어 써야 함

2) 리모션·하이퍼프레임 vs p5 (방장님 의견)
- 리모션·하이퍼프레임도 "코드로 영상을 만드는 도구"인데, 정해진 틀이 있는 레고 블럭 같은 것
- 방장님 의견: 최신 모델은 틀을 정해 주기보다 자유로운 캔버스(p5)에서 그리게 하고,
  그 다음에 "규칙"으로 틀을 잡아 가는 방식이 더 좋은 결과가 나온다
- 다른 참여자 의견: p5는 자유도가 높아 연출 폭이 넓지만, 그만큼 "안내(맥락)를 잘 줘야" 한다
- (참고: 이건 한 분의 경험담이에요. 날짜·장소·QR처럼 정보가 정확해야 하는 홍보 영상은
  하이퍼프레임처럼 틀이 있는 도구가 오히려 안정적이고, 손그림·추상 연출은 p5가 유리해요.
  둘은 섞어 쓸 수도 있어요.)

3) 잘 만드는 방법으로 나온 조언
- 레퍼런스를 보여줘라: 마음에 드는 영상(또는 캡처)을 주고 "이것처럼" 만들라고 시켜라
- 루프를 돌려라: 원하는 결과가 나올 때까지 "레퍼런스와 비교 → 고쳐줘"를 반복
- 톤을 박제하라: 마음에 드는 결과가 나오면 그 스타일(색·움직임·글꼴)을 기준으로 고정하고
  다음 콘텐츠부터는 그 기준으로 만들게 하라 → 방장님이 말한 "톤카드"
- 규칙은 만들면서 생긴다: 반복하다 보면 "이건 꼭 이렇게" 하는 규칙이 쌓이고, 그게 실력
- 맥락을 줘라: 한 줄 프롬프트로도 그럴듯한 결과는 나오지만, 흐름·연출이 있는 콘텐츠는 어렵다
  (특히 롱폼). 대본·목적·장면 흐름을 함께 줘야 한다
- 단독으로 쓰지 말고 섞어라: 모션그래픽 + 이미지 생성 + 음악(수노 등)을 조합하면 고퀄 콘텐츠
- 음악을 이해시키면 연출이 음악에 맞춰진다 (수노 음악 + 코드 영상 사례)

4) 기타
- 방장님은 1,400여 개의 모션그래픽 자료를 모아 톤별로 분류·규칙화하는 연구 중
- 10월 중 세션(강의)이 있을 예정이라는 언급이 있었음
- "하네스" = AI가 매번 같은 방식으로 작업하도록 짜 둔 작업 틀·규칙 묶음

2부. 클로드에게 모션그래픽을 잘 요청하는 법
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

■ 요청할 때 넣으면 좋은 7가지 (체크리스트)

[1] 목적·채널·규격
    예) 인스타 릴스 / 30초 / 세로(9:16)
        유튜브 롱폼 중간 B롤 / 10초 / 가로(16:9)

[2] 꼭 전달할 메시지 1개 + 필수 정보
    예) 핵심: "코딩 몰라도 AI로 웹페이지 만든다"
        필수: 날짜, 장소, 신청방법, 문의처, QR
    → 정보는 포스터·한글파일을 그대로 주면 제가 뽑아요

[3] 레퍼런스 (가장 중요!)
    - 영상 링크나 캡처를 주고 "어떤 점"이 좋은지 꼭 말해 주세요
      예) "0:12에 종이 찢어지듯 넘어가는 전환이 좋아요"
          "글자가 한 글자씩 튀어나오는 느낌"
          "색감은 이 포스터처럼"
    - 링크만 주시면 제가 영상을 직접 볼 수 없는 경우가 많아요 → 캡처 이미지가 더 확실해요

[4] 톤 (톤카드)
    - 색: 포스터·로고에서 가져오기, 또는 "민트+파랑+핑크 포인트"
    - 움직임 성격: 통통 튀게 / 부드럽게 / 각 잡히게(칼군무) / 시네마틱하게
    - 글꼴 느낌: 굵고 임팩트 / 손글씨 / 깔끔한 고딕
    - 스타일: 손그림(p5) / 깔끔한 UI 그래픽 / 3D 캐릭터 / 실사 사진 섞기

[5] 장면 흐름 (대본)
    대충이라도 순서를 주면 결과가 훨씬 좋아요
    예) ① 문제 제기(코딩 어렵죠?) → ② 해결(AI와 대화) → ③ 과정 소개
        → ④ 커리큘럼 → ⑤ 신청 방법

[6] 소리
    - 내레이션 있음/없음, 목소리 느낌(귀엽고 깔끔한 / 차분한 / 신나는)
    - 음악 분위기(트렌디한 댄스 / 국악 퓨전 / 웅장한) 또는 직접 만든 수노 곡
    - "말할 때 음악 자동으로 줄여줘(더킹)", "음악은 목소리보다 작게"

[7] 소재
    로고, 캐릭터 시안, 포스터, 사진, QR코드 → 있으면 전부 첨부


■ 피드백(수정 요청) 잘하는 법

  나쁜 예: "좀 더 멋지게 해줘"
  좋은 예: "5초쯤 채팅창 장면이 너무 빨라. 코드가 흐르는 걸 1초 더 보여줘"
          "커리큘럼 카드가 한꺼번에 나와서 정신없어. 하나씩 툭툭 나오게"
          "엔딩 QR이 너무 작아. 화면 절반 크기로"

  → [몇 초] + [무엇이] + [어떻게] 세 가지만 말하면 정확히 고칠 수 있어요
  → 마음에 드는 버전이 나오면 "이 톤으로 고정(박제)해 줘. 다음 영상도 이 기준으로"


■ 알아 두면 요청이 쉬워지는 용어

  키네틱 타이포   : 글자 자체가 움직이는 연출 (튀어나오기, 쾅 찍히기, 흔들리기)
  이징            : 움직임의 가속감 (통통 튀는 bounce / 부드러운 ease / 딱 멈추는 snap)
  스태거          : 여러 요소가 시간차로 하나씩 등장하는 것 (커리큘럼 카드처럼)
  트랜지션        : 장면 전환 (와이프, 줌, 글리치, 종이 찢기, 매치컷)
  마스크 리빌     : 가려져 있던 것이 쓱 드러나는 효과
  파티클          : 입자 효과 (반짝이, 꽃잎, 코드 조각 흩날림 → p5가 특기)
  켄번스          : 사진을 천천히 확대·이동시켜 살아 있게 만드는 효과
  비트싱크        : 음악 박자에 맞춰 장면이 바뀌거나 글자가 튀는 것
  더킹            : 말할 때 음악 볼륨이 자동으로 줄어드는 것
  립싱크          : 캐릭터 입모양을 대사에 맞추는 것


■ 바로 쓸 수 있는 요청 예시 (복사해서 고쳐 쓰세요)

  "이 포스터로 인스타 릴스 30초 홍보영상 만들어줘.
   - 핵심: 무료 교육, 19~39세 이천 청년 대상
   - 레퍼런스: 첨부 캡처처럼 글자가 쾅쾅 찍히는 키네틱 타이포
   - 톤: 포스터 색감, 통통 튀는 움직임, 굵은 고딕
   - 흐름: 문제제기 → AI 시연 → 과정 소개 → 커리큘럼 → QR 신청
   - 소리: 귀엽고 깔끔한 여성 내레이션, 밝은 테크팝, 더킹
   - 첨부: 포스터, 로고"

  "이 손그림 스타일 영상(캡처 3장)처럼 p5로 그려지는 느낌을
   이천쌀문화축제 영상 도입부 5초에 넣어줘. 밥알이가 선으로 그려지면서 등장하게."

3부. 지금까지 같이 만든 영상에서 배운 것
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

- 인삼 군무 릴스: "입모양이 대사와 맞아야" → 립싱크 / "음악 트렌디하게" → 곡 교체
  → 처음 요청에 "캐릭터가 말하는 장면은 입모양 맞춤"을 넣었다면 한 번에 끝났을 것
- 쌀축제 밥알이: 키링 사진(레퍼런스)을 보여주니 "밥그릇·밥풀" 디테일이 정확히 반영됨
  → 레퍼런스 1장이 설명 10줄보다 강력
- A/B 비교 요청("비교해 보게 하나 더")이 결정을 빠르게 해 줌 → 계속 활용 추천
- AI코딩 영상: "음악이 안 들려" → 내레이션이 긴 영상은 음악이 묻히기 쉬움
  → 요청 시 "음악도 확실히 들리게"를 넣으면 좋음
