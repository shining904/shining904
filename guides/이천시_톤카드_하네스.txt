톤 A. 3D 캐릭터 칼군무 패러디 릴스
(대표작: 이천 인삼 군무, 이천쌀 밥알이)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[결정 사항 11]
 1. 주인공    : 특산물 의인화 캐릭터 1명(대장). 의상·소품은 대장만, 군무단은 기본형
 2. 조연      : 같은 캐릭터 수백 명의 군무단 + 작은 펫(선택)
 3. 배경      : 실제 이천 느낌의 장소(논, 계단, 들판), 해 질 녘 황금빛
 4. 색        : 따뜻한 골드·앰버 / 자막은 노랑 글자 + 검은 테두리
 5. 글꼴      : 굵은 제목체(Black Han Sans), 자막은 화면 위쪽 1/4
 6. 움직임    : 대장은 무표정·진지하게 → 웃음 포인트, 군무는 각 잡힌 동시 동작
 7. 장면 구성 : 4장면 × 7.5초 (대장 등장 → 군무 → 클로즈업 → 축제 안내)
 8. 전환      : 박자(마디)에 맞춰 "툭" 끊는 컷. 끊는 맛이 이 톤의 리듬
               클로즈업은 음악 드롭(15초)에 맞춰 등장
 9. 소리      : 화면 밖 내레이터(첫·끝) + 캐릭터 대사(입모양 맞춤) + 트렌디한 댄스곡
10. 엔딩      : 흐린 마지막 장면 위에 축제명·날짜(빨간 알약)·장소·프로그램 칩
11. 금지      : 대사 없는 무음 캐릭터 / 입모양 안 맞는 대사 / 설명이 필요한 말장난

[목표 숫자] (인삼·쌀 실측 기준)
 - 길이 30초, 장면 전환 3회(7.5초마다, 마디 단위)
 - 평균 밝기 65~110 (어두우면 군무가 안 보임 → 70 이상 권장)
 - 움직임 양 10~14
 - 음량 -14~-15 LUFS, 대사 중 음악은 40%까지 부드럽게 줄임(더킹)
 - 캐릭터 얼굴이 화면 가로의 1/3 이상 (입모양 맞춤 성공 조건)

톤 B. 정보형 키네틱 모션그래픽 릴스
(대표작: 이천시 청년 AI바이브 코딩 교육)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

[결정 사항 11]
 1. 주인공    : "정보" 자체 + 안내 마스코트(로봇 등) 1개
 2. 조연      : UI 카드, 채팅창, 커리큘럼 카드, QR
 3. 배경      : 포스터 색감 그라데이션 / 도입은 어두운 코드 화면으로 대비
 4. 색        : 포스터에서 그대로 추출 (예: 민트·파랑·핑크·초록)
 5. 글꼴      : 제목 Black Han Sans, 본문 Noto Sans KR 굵게
 6. 움직임    : 글자 쾅(크게→제자리), 카드 시간차 등장(스태거), 통통 튀는 배지
 7. 장면 구성 : 문제제기 → 시연 → 타이틀 → 핵심 정보 → 신청(가장 길게)
 8. 전환      : 끊기지 않게 이어 주기. 내레이션 문장 단위로 장면이 바뀜
               (개선 과제: 마스코트가 다음 장면으로 걸어 들어가는 식의 연결 소품)
 9. 소리      : 처음부터 끝까지 내레이션 + 밝은 테크팝, 음악도 확실히 들리게
10. 엔딩      : QR 크게(실제로 스캔되는지 확인) + 문의처 + 로고
11. 금지      : 포스터와 다른 날짜·장소 / 작은 글씨 정보 나열 / 스캔 안 되는 QR

[목표 숫자] (AI코딩 실측 기준)
 - 길이 30초, 장면 전환 4~5회(5~6초마다, 내레이션 문장 단위)
 - 평균 밝기 130~150 (밝고 산뜻하게)
 - 움직임 양 10~13
 - 음량 -14~-15 LUFS, 말하는 중 음악이 목소리보다 약 9dB 작게
   (20dB 이상 차이 나면 음악이 안 들림 - 실제로 있었던 실수)

오답노트 (실수 → 규칙)  ※ 계속 추가
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 - 인삼 1차: 대사·내레이션 없이 음악만 → 캐릭터 영상은 소리 구성부터 확인
 - 인삼: 넓은 화면에서 입모양 맞춤 실패 → 얼굴 크게(화면 1/3 이상) 찍고 맞춤
 - 인삼: 입에 뿌리 문 캐릭터는 입이 안 움직임 → 그 대사는 화면 밖 내레이터로
 - 밥알이: 선으로 그린 입은 입모양 맞춤이 약함 → 대사 구간에 "입을 벌려 말하는" 장면을 먼저 생성
 - 밥알이: "칼군 / 무" 이상한 줄바꿈 → 긴 자막은 줄을 직접 나눔
 - 밥알이: "88번 손이 갔다"는 설명이 필요 → 설명 없이 바로 이해되는 카피 사용
 - 마사회: 장면 전환 효과음이 너무 큼 → 효과음은 음악보다 작게
 - 마사회 가로영상: 첫 장면 어두움 → 평균 밝기 하한 확인
 - AI코딩: 음악이 안 들림(목소리보다 20dB 작음) → 음악·목소리 크기 차이 측정
 - 공통: 실제 아이 얼굴 영상은 생성 차단됨 → 얼굴 없는 연출이나 캐릭터로 대체
